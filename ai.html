How it works

Fixed rules, not guesswork.

QuantAI makes the same decision a careful statistician would, every time, and shows you why.

Assumptions decide the test

Shapiro–Wilk for normality, Brown–Forsythe for equal variances, and Cochran's rule for expected counts choose between t-tests, Welch, Mann–Whitney, ANOVA, Kruskal–Wallis, chi-square and Fisher's exact test.

Models with diagnostics

Linear, logistic, Poisson and modified Poisson regression with crude and adjusted estimates, VIF, events per variable, Breusch–Pagan, Hosmer–Lemeshow, ROC and overdispersion checks. Robust standard errors switch on when needed.

Reproducible by design

Every analysis exports as Stata, Python, R and SPSS code that reads the same cleaned file and recodes it the same way, so you can check every number in your own software.

A significant result shows an association, not that one thing causes another. For a thesis, publication or decision with real consequences, get in touch about a full analysis.
